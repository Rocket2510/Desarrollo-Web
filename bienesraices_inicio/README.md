# 🏠 Sitio Web de Bienes Raíces

Sitio web desarrollado para la venta y promoción de propiedades inmobiliarias, con panel de administración y funcionalidades completas tanto para el usuario como para el administrador.

## 📌 Módulos principales

- **Nosotros:** Información sobre la empresa o agente inmobiliario.
- **Anuncios:** Lista de propiedades en venta con detalles.
- **Blog:** Artículos informativos o consejos sobre bienes raíces.
- **Contacto:** Formulario para enviar mensajes.

## 🔐 Panel de Administración

- Login seguro para administradores.
- Alta, edición y eliminación de propiedades.
- Carga de imágenes con nombre único para evitar conflictos.
- Las propiedades se actualizan directamente en el sitio web.

## 🌐 Tecnologías utilizadas

- HTML5  
- CSS3 / Sass  
- JavaScript  
- PHP  
- MySQL  
- Node.js  
- Gulp  

## ✨ Características destacadas

- Diseño completamente responsivo
- Modo oscuro (basado en preferencias del sistema o selección manual)
- Administración eficiente de propiedades e imágenes
- Automatización del desarrollo con Gulp
