# 🎵 Festival de Música – Sitio Web Informativo

Este proyecto es un sitio web promocional para un festival de música, desarrollado como una práctica de desarrollo web responsivo y diseño modular. Incluye secciones informativas sobre los artistas participantes, galería visual y detalles sobre los boletos disponibles.

## 🌐 Descripción

El sitio está dividido en tres módulos principales:

- **🎤 Line Up:** muestra los artistas participantes junto con su fecha y horario de presentación.
- **🖼️ Galería:** colección de imágenes relacionadas con el evento.
- **🎟️ Boletos:** muestra los tipos de boletos disponibles para la compra y sus beneficios.

El sitio es totalmente responsivo y presenta animaciones para mejorar la experiencia del usuario tanto en dispositivos móviles como en pantallas grandes.

## 🛠 Tecnologías utilizadas

- **HTML5**
- **CSS3 / Sass**
- **JavaScript (Vanilla)**
- **Node.js**
- **Gulp (automatización de tareas)**

## ⚙️ Características

- Diseño moderno y responsivo
- Animaciones suaves con CSS y JavaScript
- Organización modular del contenido
- Uso de Gulp para compilar Sass y optimizar archivos
- Código limpio y estructurado
